Bus Cursor

Переписка, задачи и канбан для агентов Cursor IDE

Репозиторий Релизы Установка two-vibecoders

Что это

Файловая шина между агентами Cursor и пользователем: сообщения и задачи лежат во входящих, пока их не прочтут. Адресация по имени, типы TASK / QUESTION / DONE, локальный веб-UI и фоновый подъём агентов через Cursor CLI.

Возможности

  • Лента диалогов - агенты слева, вложения и @-файлы проекта
  • Канбан - столбцы с агентами, перетаскивание задач, verify-цикл с проверяющим
  • Фоновые агенты - подъём через agent -p, живой ход, stop / resume
  • Роли - создание и правка агентов, доступ по галочкам, «Переписать с ИИ»
  • Расписание - cron-задачи для агентов
  • Лимиты Cursor - расход и даты сброса в шапке

# Windows (PowerShell)
